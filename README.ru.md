# Установка и обновление ChatGPT на Windows — исправление ошибок

**ChatGPT не устанавливается или не обновляется?** Этот PowerShell-скрипт проверяет Windows, получает официальный пакет приложения и помогает с ошибками Microsoft Store / MSIX, включая **`0x80073D28` — требуются права администратора**.

**[Скачать ZIP](https://github.com/w1zardz/chatgpt-windows-installer/releases/latest/download/ChatGPT-Windows-Installer.zip)** · [English](README.md) · [Справочник ошибок](docs/TROUBLESHOOTING.md)

Независимый проект сообщества. Не является официальным продуктом OpenAI или Microsoft. Исправление абсолютно всех причин не обещается.

## Запуск

1. Скачайте ZIP и **распакуйте всю папку**.
2. Дважды нажмите **`Start.cmd`**.
3. Если Windows запросит права администратора, подтвердите установку.

Скрипт определит x64 или ARM64, проверит установленную и доступную версии, скачает пакет с сервера OpenAI, проверит подпись и совместимость, затем запустит установку. Для следующих обновлений достаточно снова запускать `Start.cmd`. Актуальная или более новая версия повторно не устанавливается.

Если ChatGPT открыт, обновление может ожидать закрытия приложения. **Сохраните работу, полностью закройте ChatGPT, включая значок возле часов, и откройте снова. Повторный запуск скрипта проверит установленную версию.** Ожидающее применения обновление не выдаётся за завершённую установку.

Запрос прав Windows остаётся обязательным. Если пароль администратора отсутствует, скрипт его не заменит. При вводе данных другого администратора выполнение остановится: приложение не должно случайно установиться для чужой учётной записи.

## Что проверяется и исправляется

Автоматически выполняются подбор пакета, получение актуальной версии, запрос прав, безопасная повторная загрузка при временном обрыве, проверка подписи, установка или обновление. Скрипт не понижает версию и не завершает работающие приложения принудительно.

Диагностика также проверяет версию Windows, свободное место, состояние пакета, зависимости, некоторые службы и политики, необходимость перезагрузки и события установки. Справочник распознаёт распространённые ошибки прав, MSIX, сети, DNS/TLS, сертификатов, конфликтов и Microsoft Store. Для причин, требующих ИТ или восстановления Windows, выводятся рекомендации.

Скрипт не удаляет переписку или данные приложения, не отключает антивирус, SmartScreen, брандмауэр и проверку сертификатов, не меняет регион и системные политики. Повреждение Windows, ограничения организации, блокировку аккаунта и недоступность сервиса невозможно гарантированно исправить одним установщиком.

## Почему в ошибке написано OpenAI.Codex, а приложение называется ChatGPT?

Цель скрипта — нынешнее приложение ChatGPT для Windows с идентификатором пакета **`OpenAI.Codex`** и номером Microsoft Store **`9PLM9XGG6VKS`**. Этот идентификатор указан в [документации OpenAI](https://learn.chatgpt.com/docs/enterprise/windows-deployment).

Старое отдельное приложение `OpenAI.ChatGPT-Desktop`, если оно установлено, распознаётся отдельно. Скрипт его не удаляет и не переносит его данные. Это не обновлятор старого пакета на месте.

## Россия, Российская Федерация и переезд

Если раньше вы пользовались Microsoft Store или аккаунтом Microsoft в России, а затем переехали, проверьте, соответствует ли **страна в настройках Windows и профиле Microsoft вашему фактическому положению**. Доступность приложений зависит от региона; Microsoft описывает изменение страны после длительного переезда в [официальной инструкции](https://support.microsoft.com/en-us/accounts-billing/change-your-country-or-region-in-microsoft-store).

Сам по себе русский язык, гражданство или любая «связь с Россией» не доказывают причину ошибки установки. Скрипт не делает таких выводов, не проверяет историю аккаунта и не определяет страну по IP. Даже ответ сервера `403` не даёт оснований уверенно объявить причиной регион.

На дату проверки документации, **22 сентября 2026 года**, России нет в [списке поддерживаемых OpenAI стран](https://help.openai.com/en/articles/7947663). Проверяйте актуальный список по ссылке. Успешная установка приложения и доступность ChatGPT — разные вещи: скрипт не снимает ограничения сервиса. После переезда он может помочь с локальной установкой в поддерживаемых условиях, но не гарантирует устранение проблем аккаунта или региона.

## Если уже устанавливали через PowerShell

Ручная установка **не означает, что встроенное обновление навсегда отключено**. Этот скрипт даёт дополнительный способ обновить приложение при проблемах обычного установщика. Он ничего не добавляет в автозагрузку или планировщик и не обновляет сам себя в фоне.

## Диагностика без установки

Дважды нажмите **`Diagnose.cmd`**. Это чтение состояния компьютера и проверка доступной версии; приложение не устанавливается, права администратора не запрашиваются.

Для полностью локальной проверки без интернета:

```powershell
.\Install-ChatGPT.ps1 -Mode Diagnose -Offline -Language ru
```

Чтобы только скачать и проверить официальный пакет:

```powershell
.\Install-ChatGPT.ps1 -Mode Download -Language ru
```

Команды выполняются из распакованной папки в Windows PowerShell. Если политика запуска блокирует `.ps1`, используйте готовые `.cmd`. Они задают разрешение выполнения только своему процессу, не изменяя настройки Windows. Политики организации не обходятся.

## Отчёт и требования

Текстовый отчёт и JSON сохраняются в `%LOCALAPPDATA%\ChatGPTWindowsInstaller\reports`. Отчёты не отправляются разработчику. В них нет переписки, паролей, токенов, имён пользователей, SID и исходных сообщений журнала с личными путями. Версии Windows/приложения, регион Windows, состояния отдельных служб/политик и коды ошибок включаются; перед публикацией прочитайте отчёт.

Нужны Windows 10 сборки 19041+ или Windows 11, x64/ARM64, Windows PowerShell 5.1, компоненты AppX и место для загрузки/распаковки пакета. Минимальная версия из самого пакета проверяется дополнительно. `Start.cmd` выбирает штатный Windows PowerShell.

Коды завершения: `0` — выполнено/актуально; `1` — ошибка; `2` — требуется действие пользователя или администратора; `10` — Windows приняла обновление, но его применение ещё нужно подтвердить после перезапуска приложения.

## Проверка проекта

Исходный код открыт. ZIP содержит скрипты, а не переупакованный ChatGPT. Пакет скачивается только с сервера OpenAI и проверяется средствами Windows. Контрольная сумма ZIP находится в `SHA256SUMS.txt` рядом с релизом; она проверяет целостность загрузки, а не личность издателя. Скрипты сообщества не подписаны Authenticode.

Автоматические тесты моделируют установку и ошибки, не устанавливая приложения на машине тестирования. Реальные установка на чистой системе, все корпоративные конфигурации и ARM64 не считаются проверенными только на основании этих тестов.
